## Задание 1
### Парадигма
* Функциональная
* ООП
* Императивная
### Язык программирования 
* C++
* Go
* Python
### Обоснование
Go и C++ подходят для решения этой задачи, потому что эти ЯП могут обеспечить бесперебойную устойчивую к нагрузкам работу 24/7. В C++ можно контролировать память и это позволяет повысить производительность, тем самым позволяя оптимизировать математическую обработку изображений. Go проще в поддержке, хорошо подходит для потоковой обработки. Python подходит только с ускорением через CUDA, т.к. в нем есть много библиотек для работы с изображениями, а также библиотеки с математическими функциями. Если системе не нужно держать большую нагрузку, то Python должно хватить, но это не желательный вариант.
Функциональная парадигма полезна для чистых математических преобразований, ООП — для структуры системы, императивная — для ручной оптимизации критичных участков.

## Задание 2
### Парадигма
* ООП
* Императивная
* Функциональная 
### Язык программирования 
* Python
### Обоснование
Python позволяет быстро писать MVP и прототипы. Популярные ML-библиотеки (scikit-learn, PyTorch, TensorFlow, pandas) содержатся в Python. Для прогноза погоды раз в сутки нет высоких требований к реальному времени, поэтому производительности Python достаточно. Можем использовать императивную парадигму и ООП. Если хотим развивать сервис и поддерживать его в будущем используем ООП. Если хотим просто сделать прототип и в будущем не хотим возвращаться к нему, можно использовать императивный подход. Функциональная парадигма может пригодиться для чистых функций предобработки данных, данная парадигма не основная.

## Задание 3
### Парадигма
* Декларативная
* Событийно-ориентированная
* ООП
### Язык программирования 
* JavaScript
* TypeScript
* HTML
* CSS
### Обоснование
Для веб-интерфейсов используют JavaScript или TypeScript. TypeScript (коммерческий стандарт) предпочтительней, т.к. строгая типизация снижает кол-во ошибок. Для разметки используют HTML и CSS. Декларативная парадигма, потому что используем HTML и CSS.  Событийно-ориентированная парадигма нужна для реакции на действия пользователя и потоки данных. ООП/функциональная парадигмы помогают организовать состояние виджетов и чистые преобразования.

## Задание 4
### Парадигма
* Императивная
* Процедурная
### Язык программирования 
* Rust
* C++
* C
* Zig
### Обоснование
Эти ЯП эффективно используют память. Код на этих языках получается быстрым и оптимизированным по расходу памяти. ЯП без сборщика мусора и динамических аллокаций позволяют точнее контролировать энергопотребление. С - классический выбор. Дает доступ к памяти и регистрам. Rust дает безопасность памяти, но нужно будет учитывать совместимость с микроконтроллером. С++ используем без тяжелых абстракций классов. Zig также подходит благодаря контролю над памятью и простоте, но язык новый и еще не имеет стабильной версии. Императивная/процедурная парадигма здесь основная, потому что код должен быть детерминированным и предсказуемым.
