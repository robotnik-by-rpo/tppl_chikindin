# Стековая машина с постфиксная нотация 

В корневой директории postfix_notation находится Makefile. Он имеет следующие таргеты.
### Таргеты
|таргет|описание|
|------|--------|
|run EXP="ваша постфиксная нотация"|Запуск программы|
|venv|Создает python виртуальное окружение|
|test-install|Установка pytest|
|test-cor|Получить процент покрытия тестами кода|
|help|Выводит вспомогательную информацию о программе|

Для проверки работоспособности достаточно запустить 3 таргета: run EXP="ваша постфиксная нотация", help, test-cor
